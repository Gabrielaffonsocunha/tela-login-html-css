# Tela de Login — HTML e CSS

Protótipo visual de uma página de login, desenvolvido para praticar posicionamento com Flexbox, composição visual e organização básica de arquivos front-end.

## Tecnologias

- HTML5
- CSS3

## Como executar

1. Clone ou baixe este repositório.
2. Abra `enter.html` em um navegador moderno.

## Estrutura

- `enter.html`: estrutura da interface
- `style.css`: estilos e layout

Este projeto é somente uma demonstração de interface. Não possui autenticação, armazenamento de credenciais ou backend. Não insira senhas reais.
